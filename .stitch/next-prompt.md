Создать страницу-галерею реализованных интерьеров «Живой Омск» для Центра декора «Крафика».

**DESIGN SYSTEM (REQUIRED):**
- **Основные цвета:**
  - Фон 1: `#EFEFEA` (Warm Gray / Bone)
  - Фон 2: `#D5C7B7` (Warm Beige / Sand)
  - Текст основной: `#1C1C1A` (Charcoal)
  - Текст акцентный: `#B89B64` (Muted Gold / Ochre)
  - Кнопки (CTA): `#132D42` (Deep Navy)
- **Типография:** High-contrast Serif для H1/Display (Playfair Display) и геометрический гротеск Inter для контента.
- **Сетка:** Асимметричная журнальная верстка с большими отступами (XL Whitespace) и абсолютно острыми углами кнопок.

**Page Structure:**
1. Хедер с меню и логотипом (из сквозного макета)
2. Заголовок первого уровня (Display Serif): «Наши стены в живых интерьерах Омска»
3. Фильтр галереи по категориям: Жилые квартиры / HoReCa Рестораны / Декоративная штукатурка / Микроцемент
4. Асимметричная сетка карточек проектов с перекрытием текста поверх крупных фотографий:
   - *Ресторан «Шато»* — Микроцемент DERUFA, 3 года эксплуатации, 0 сколов.
   - *Квартира в ЖК «Пушкина 77»* — Декоративная штукатурка и текстиль, гармоничное тон-в-тон сочетание.
   - *Кофейня в центре Омска* — Износостойкое нанесение за 4 ночные смены.
5. Интерактивный интерактивный до/после слайдер для демонстрации выравнивания стен и нанесения материала.
6. CTA Блок: «Хотите убедиться вживую? Запишитесь на чашку кофе и тест-драйв фактур в наш шоу-рум»
7. Футер (из сквозного макета)
