# DESIGN SYSTEM: Premium Minimalist Editorial

> **STITCH GENERATION RULES (REQUIRED):**
> Adhere strictly to this design system. Do NOT write styling instructions or CSS. Use the following descriptive language.

## 1. Visual Vibe (Adjectives)
- **Primary:** Premium Minimalist (editorial look, clean geometric borders, sharp shapes).
- **Secondary:** Warm Bone / Bone-white & Sand (soft organic colors instead of sterile whites).
- **Accent:** Muted Gold / Ochre & Deep Slate Navy (sophisticated contrast highlights).

## 2. Color Palette (Semantic)
- **Background Primary (Warm Gray / Bone):** `#EFEFEA`
- **Background Secondary (Warm Beige / Sand):** `#D5C7B7`
- **Text Primary (Charcoal / Off-black):** `#1C1C1A`
- **Text Accent (Muted Gold / Ochre):** `#B89B64`
- **UI Element / Button BG (Deep Navy / Slate):** `#132D42`

## 3. Typography
- **Display Headings (H1, Hero):** Playfair Display (High-contrast Serif / Didone style, uppercase, letters spaced tightly: `-0.02em`, very large).
- **Body & Metadata (Navigation, body text):** Inter (Neo-grotesque Sans-Serif, clean, light weights, spaced elegantly).
- **Micro-Caps:** Uppercase, very small, letter-spacing `0.15em` (`tracking-widest`).

## 4. Spacing & Composition
- **Margins:** Generous (Extra Large Whitespace, `py-24`, `my-16`).
- **Asymmetric Grid:** Dynamic magazine-style layouts with offset cards.
- **Overlap:** Headers overlapping textures or background color blocks.
- **Borders:** Minimal, sharp 1px borders in `#D5C7B7`. Zero shadow (`shadow-none`).
- **Corners:** Absolutely sharp (`border-radius: 0px`).

## 5. UI Elements
- **Buttons:** Background color `#132D42` or transparent border, text white or charcoal, sharp rectangular edges, wide padding (`px-8 py-5`).
